## ⚡ الرفع بنقرة واحدة على Vercel (1-Click Deployment)

يمكنك رفع المنصة فوراً على استضافة Vercel السحابية فائقة الأمان بضغطة زر واحدة:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FYourUsername%2Fameer-store&env=AUTH_SECRET,ADMIN_EMAILS,NEXT_PUBLIC_APP_URL,NEXT_PUBLIC_BUSINESS_PHONE,NEXT_PUBLIC_BUSINESS_WHATSAPP,POSTGRES_URL,CLOUDINARY_URL,RESEND_API_KEY&envDescription=Configuring%20Ameer%20Store%20Luxury%20Perfume%20Platform)

أو استخدم أداة الرفع المؤتمتة محلياً عبر سطر الأوامر:
```bash
deploy.bat
```
تقوم أداة `deploy.bat` تلقائياً بفحص الأنواع (Typecheck)، تدقيق الأمان (ESLint)، تشغيل حزمة الاختبارات الشاملة، بناء النسخة الإنتاجية، ثم رفع المتجر مباشرة إلى Vercel الإنتاجي بنجاح تام.

## ☁️ منظومة الخدمات السحابية المجانية (Free Production Cloud Services)

تم تجهيز المتجر للربط التلقائي بثلاث خدمات سحابية عالمية توفر باقات مجانية سخية تكفي للتشغيل الإنتاجي، مع هبوط آمن وتلقائي (Graceful Fallback) للتخزين المحلي في حال عدم إدخال المفاتيح:

| الخدمة السحابية | المزود المعتمد | الباقة المجانية | الميزة التشغيلية |
| :--- | :--- | :--- | :--- |
| **قاعدة البيانات (Database)** | [Neon](https://neon.tech) / Vercel Postgres | 0.5 GiB تخزين مجاني دائم | حفظ الطلبات والمنتجات سحابياً مع الترحيل التلقائي وزرع الكتالوج |
| **تخزين الصور (Media Storage)** | [Cloudinary](https://cloudinary.com) | 25 GB شهرياً مجاناً | رفع وحفظ صور العطور من لوحة التحكم مع CDN عالمي فائق السرعة |
| **البريد التلقائي (Transactional Email)** | [Resend](https://resend.com) | 3,000 إيميل مجاناً شهرياً | إرسال فواتير ملكية عربية للعميل وإشعار فوري لبريد الإدارة |

### ⏱️ تفعيل الخدمات السحابية في دقيقتين:
1. **قاعدة البيانات:** انسخ رابط الاتصال من [Neon](https://neon.tech) وضعه في `POSTGRES_URL`.
2. **تخزين الصور:** انسخ رابط البيئة من [Cloudinary](https://cloudinary.com) وضعه في `CLOUDINARY_URL`.
3. **البريد الإلكتروني:** أنشئ مفتاح API مجاني من [Resend](https://resend.com) وضعه في `RESEND_API_KEY`.

## 🛠 التقنيات المستخدمة (Tech Stack)
- **الإطار البرمجي (Framework):** [Next.js 15](https://nextjs.org/) (App Router & React 19)
- **لغة البرمجة:** [TypeScript 5](https://www.typescriptlang.org/) (Strict Mode)
- **قواعد البيانات السحابية:** محرك هجين يدعم Vercel Postgres / Neon مع الترحيل التلقائي للجداول (Auto-DDL) وزرع العطور الثمانية تلقائياً، مع هبوط آمن للتخزين الذري المحلي `withStorageMutex`.
- **التخزين السحابي للوسائط:** Cloudinary Free Tier (25GB) مع دعم التحويل التلقائي لـ WebP والرفع الذكي، مع هبوط آمن للمجلد المحلي `public/uploads/`.
- **البريد الإلكتروني:** Resend Transactional Emails مع قالب فاتورة ملكي عربي بالذهب والكشمير، مع محاكاة تلقائية عند غياب المفتاح.
- **الأنيميشن والحركة:** [GSAP 3](https://greensock.com/gsap/) و `@gsap/react` مع دعم الإحداثيات المنطقية لـ RTL
- **التصميم وتنسيق الواجهات:** [Tailwind CSS](https://tailwindcss.com/) مع نظام رموز تصميم مخصص لعلامة أمير ستور (Cashmere, Deep Forest Olive, Royal Metallic Gold `#D4AF37`)
- **الأيقونات:** [Lucide React](https://lucide.dev/)
- **الخطوط:** Amiri للنصوص الملكية، Cinzel للرموز اللاتينية، و Cairo للتصفح السريع
- **إدارة الأمان والطلبات:** Server-Authoritative Pricing لحساب الأسعار وتكاليف الشحن حصراً على السيرفر مع تقييد معدل الطلبات (Rate Limiting).

## 🚀 بدء التشغيل المحلي (Getting Started)

1. **تثبيت الحزم البرمجية:**
   ```bash
   npm install
   ```

2. **إعداد متغيرات البيئة:**
   انسخ ملف `.env.example` إلى `.env.local` وراجع الإعدادات:
   ```bash
   copy .env.example .env.local
   ```

3. **تشغيل خادم التطوير:**
   ```bash
   npm run dev
   ```
   افتح المتصفح على [http://localhost:3000](http://localhost:3000).

4. **فحص الأنواع وتدقيق الشيفرة والاختبارات الآلية:**
   ```bash
   npm run typecheck
   npm run lint
   npm test
   npm run build
   ```

## 🧪 حزمة الاختبارات الآلية الشاملة
تتضمن المنصة حزمة اختبارات مؤتمتة رباعية المستويات (`scripts/run-tests.js`) بنسبة نجاح 100%:
- **Tier 1:** تغطية الميزات الأساسية والكتالوج ونظام الأسعار.
- **Tier 2:** صد محاولات الاختراق، التلاعب بالأسعار، والمدخلات الخبيثة.
- **Tier 3:** التفاعل المركب بين السلة، الشحن، التزامن، والتدفق المزدوج.
- **Tier 4:** محاكاة رحلات الشراء الواقعية من الاختيار حتى التسليم.
