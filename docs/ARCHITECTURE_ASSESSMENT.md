# أمير ستور (Ameer Store) — المعمارية البرمجية والتحصينات الأمنية

## المتجر الرسمي للعطور الفاخرة ودهن العود الملكي

### 1. الأهداف المعمارية
1. **عزل البيانات والأمان:** الفصل التام بين منطق المتجر والواجهة، مع اعتماد التسعير الحصري من السيرفر (Server-Authoritative Pricing) لمنع أي تلاعب بأسعار العطور أو إجماليات السلة من المتصفح.
2. **التدفق المزدوج للشراء (Dual Flow):**
   - الدفع عند الاستلام (Cash on Delivery) مع احتساب الشحن آلياً (شحن مجاني للطلبات فوق 1000 ج.م).
   - الطلب المباشر عبر الواتساب الموثق: توليد كود رسمي `AMR-XXXXXX` وحفظ الطلب في قاعدة البيانات وتفريغ السلة قبل فتح محادثة الواتساب مع العميل.
3. **الهوية البصرية والحركة الراقية (Quiet Luxury):**
   - تصميم عربي ملكي بنظام ألوان الكشمير، الزيتوني، والذهب الخالص.
   - حركات ناعمة باستخدام مكتبة GSAP بدون أي وميض أو تأثير سلبي على الأداء.

### 2. البنية التحتية
- **Next.js 15 App Router** مع React 19.
- **Strict TypeScript** لتأكيد صحة البيانات وأنواع الطلبات والمنتجات.
- **Tailwind CSS** مع Logical Properties لدعم اتجاه اليمين لليسار (`dir="rtl"`).
- **In-Memory Mutex Queue (`withStorageMutex`)** لمنع تعارض الكتابة المتزامنة عند تعدد الطلبات في نفس اللحظة.
